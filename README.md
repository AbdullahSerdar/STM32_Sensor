#STM32F4

[EN] These codes are basic implementations for certain sensors on the STM32 board. The final, fully optimized versions where the sensors work together are not shared here.
As I find time, I will gradually improve these shared codes individually and also add other sensor codes I have developed.

[TR] Bu kodlar, STM32 kartındaki belirli sensörler için temel uygulamalardır. Sensörlerin birlikte çalıştığı son, tamamen optimize edilmiş sürümler burada paylaşılmamıştır.
Zaman buldukça, bu paylaşılan kodları tek tek kademeli olarak geliştireceğim ve geliştirdiğim diğer sensör kodlarını da ekleyeceğim.
